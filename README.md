# ADÉ STUDIOS Website v1.0

A mobile-first static website for ADÉ STUDIOS. Built with plain HTML, CSS and JavaScript.

## Included
- Responsive layout (mobile, tablet, desktop)
- Five service divisions
- About section and values
- Process section
- Demonstration portfolio (clearly labelled as concepts)
- Contact CTA and WhatsApp link setup
- Mobile navigation
- SEO title and description
- SVG logo/favicon assets

## Before publishing
1. Open `script.js`.
2. Set `WHATSAPP_NUMBER` to the official number in international format, digits only. Nigeria example: `2348012345678`.
3. Review the content and replace any details that are not yet confirmed.
4. The portfolio pieces are demo concepts and must not be represented as completed client work.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `ade-studios-website`.
2. Upload all files and folders from this package (keep the `assets` folder).
3. In repository Settings → Pages, select deployment from the `main` branch and root folder.
4. Save. GitHub Pages will provide a public URL after deployment.

## Custom domain
You can connect a domain later. Do not purchase one until the business is ready and the budget permits.
